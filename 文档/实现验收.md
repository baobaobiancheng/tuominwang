# M1 基础工程验收

日期：2026-09-21。结论：基础工程与文本规则闭环已实现并通过本机验证；不代表完整 R1、三层脱敏或生产发行通过。

## 实现范围

已实现登录、创建者独占项目、不可变文本加密保存、数据库持久任务、规则识别、人工确认/排除/补标、版本冲突检查、TXT 类型占位符替换、实际产物核验及限时下载。没有模型调用，没有把 NER/AI 未执行显示为无命中。原文不覆盖，不自动清理既有数据。

按 ponytail full 控制范围：共用原生 crypto 与文件系统、参数化 SQL 和数据库约束；没有 Redis、通用插件工厂、模拟模型服务或尚未需要的模型实现类。安全校验和可执行测试未省略。

## 修复记录与保留事项

验证中修复了 PostgreSQL 函数保留字冲突、下载路由长度限制、文件未生成时下载按钮提前启用、只读选区捕获、开发服务器敏感目录访问范围，并升级了有已知漏洞的开发依赖。GCM 解密明确要求 128 位认证标签。

启动并行进程时，Vite 可能在 API 就绪前记录短暂代理连接失败；端到端入口等待 `/api/health` 成功后才开始测试。NO_COLOR/FORCE_COLOR 冲突提示不影响功能。完整系统的 OCR/NER/AI、复杂格式、可逆映射、成员协作、备份恢复、发行与正式评测仍未完成，历史评审待确认项不视为默认批准。

复现与启动见 [README](../README.md)。测试创建合成账号、项目及产物并保留在本机；不自动删除用户材料。后续若在有待处理业务任务的环境运行集成测试，应使用独立测试数据库。

## 2026-09-21：审查问题修复与 UI 规范对齐

四项审查问题均已修复：

| 问题 | 修复与回归证据 |
|---|---|
| 下载未绑定页面版本 | 下载请求必传 `revision`，在文档行锁内比较；旧窗口请求返回 409，不签发新链接。集成测试创建第二版低脱敏产物，证明第一版页面不能静默下载它。原有已签发链接到期前可用的约定不变。 |
| 轮询绕过版本冲突 | 编辑或请求处理中暂停轮询，已在途的旧响应也不覆盖草稿。浏览器延迟响应与另一窗口改版回归：本地仍以原始版本提交并收到冲突；明确确认后才能重新载入。 |
| 保存期间的新编辑丢失 | 原生 `fieldset disabled` 与同步请求锁共同禁止处理中编辑、补标、删除、重复请求或切换；锁持续到重新读取完成。保存和文本提交各有慢请求回归。取消任务仅刷新任务状态，不清除复核草稿。 |
| 大量标记无法保存 | 共用 100 KiB 文本上限、32,768 项复核上限及专用 HTTP 请求容量；覆盖现有三种规则最短匹配长度下的命中数量上界。真实 API 完成 12,000 个邮箱的保存、导出、下载与字节比对。前端每页 50 项，但完整保存全部页，跨页修改有回归。 |

UI 依据 [Token Spec V2](../../ui设计/image.png) 和 LegalOS 详情源稿，采用 `#2563EB` 品牌蓝、中性灰白、语义反馈色、20/28 页面标题、16/24 区块标题、14/22 正文、36px 常规控件、20px 卡片内边距与 24px 桌面页面边距。普通卡片无阴影，无新增 UI 依赖、远程字体或虚设 AI 入口；登录页和工作台均覆盖 390px 手机宽度。

本轮验证：`pnpm check` 通过（类型、6 项核心测试、构建）；隔离 PostgreSQL 集成测试通过；Playwright 7 项通过（6 项确定性浏览器回归＋1 项真实登录到下载闭环）。浏览器并发回归只模拟接口时序，版本拒绝、加密产物和大批量保存由真实 API/数据库测试验证。临时测试数据库已在完成后删除，未写入既有业务数据库；合成测试密文产物留在忽略目录 `.data/review-tests/`。
