## 已实现的对应关系

| 脱敏猫已观察结构 | 脱敏汪本轮实现 | 保留的实际差异 |
|---|---|---|
| 深紫顶栏/导航、浅紫工作区、白色面板 | 全局紫色视觉令牌；登录、项目、管理、复核共用组件规范 | 自有产品名、字体和组织权限 |
| 左文档 / 中正文 / 右敏感信息 | 左侧增加当前项目材料导航；正文和右侧复核独立滚动 | 侧栏兼容项目切换与折叠 |
| 工具集中、全文检查按需打开 | 右侧切换敏感标记、全文查找、批量复核、漏标检查 | 采用工具视图，不照搬模态窗 |
| 固定操作区 | 工具栏和保存/生成/下载区稳定；中间两栏占剩余高度 | 保存与导出是独立动作，保留版本/权限/未确认项限制 |
| 按类型着色 | 原文候选高亮，标记卡使用相同类型颜色；保留项不高亮 | pending/redact 仍有明确文字状态，高亮不是脱敏产物 |
| 右侧类型与同值分组 | 后续已增加当前材料同类型、完整同值分组及逐处编辑 | 长原值按位置独立；全项目同值树仍未实现，见工作流记录 |

高亮背景镜像不会改动原文或标记 UTF-16 偏移。重叠范围采用确定的视觉优先级，但导出仍须人工解决范围冲突；不会因为一层颜色覆盖另一层而自动认可重叠。长文仍使用现有 32,768 字符窗口，跨窗查找/补录沿用完整文档接口。

组织管理页属于本工具的多人权限功能。脱敏猫静态路由只有工作台、图片审查、激活等入口，不能声称存在一个相同的组织成员页可以逐像素复刻。

## 对抗性审查与修复

用户授权后启动独立子 agent：前端证据分析、权限/状态审查、高亮组件实现；随后进行两名 reviewer 的独立只读复审。

| 发现 | 修复 | 验证 |
|---|---|---|
| P2：无假名映射权限的复核者可补录继承假名的漏标，导致整份草稿保存 403 | 检查结果仍可查看；补录前按权限阻止会继承假名的新增操作，说明原因；服务端权限不放宽 | 真实隔离账号操作：不能补录，仍可保存正常复核 |
| P2：深色 aside 后代规则把白底新建项目/组织弹窗文字染浅 | 深色文字规则只作用侧栏导航；新建项目显式正常文字色；弹窗保持原规范 | 实际浏览器对可操作文字检查 >=4.5:1 对比度 |
| 滚动边界风险：尾换行可能让 pre 与 textarea 高度不同 | 背景层 CSS 零宽尾占位，同字体/行高/换行/滚动槽，同步滚动 | 三种宽度、65 行含 emoji 与尾换行，内容宽高/末尾滚动差测量 |
| 浏览器运行器退出停留 | 第一批完成后清理本轮 worker；后续使用与部署同主版本的 Node 24 | 后续测试正常自行退出；没有停止业务容器 |

最终两名 reviewer 均返回 No findings。这是代码审查结论，独立于下面的运行检查。
