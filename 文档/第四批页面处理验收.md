# PDF 与图片区域处理验收

## 已实现

- 迁移 007 增加页面复核策略、快照绑定的页面资源清单、产物格式；不改写原件和旧快照。旧页面资料须保存新的复核版本后导出。
- 桌面框选与坐标输入，敏感区域/印章/签名/人脸的人工区域标签，同一比例区域应用到指定多页，删页及最近 10 步页面撤销。
- 待确认文字在处理预览中保持原值；预览不是已签发下载文件。页面和文字决定统一使用预期版本保存，快照不可修改。
- PDF 必须明确选择“不可选字的图片型 PDF”；图片明确选择 PNG 副本。PDF 保留规范化后的页面尺寸与方向，但不保留可选字、图层、表单、链接、签名有效性及文件属性。不得将此能力表述为原生 PDF 结构回写。
- 根据原有字形/OCR 坐标清除已确认文字像素，人工选区直接清除 RGB 字节。缺少字形定位的非空白字符阻断，不跳过；不支持在此导出模式使用假名、部分遮盖和自定义替换。
- 新 PDF 仅包含从清除后 RGB 编码的页面图像，不复制原始 PDF 对象。重新打开检查页数、元数据、附件、脚本、可提取文字，并逐字节核对重新渲染的像素。
- PNG 重解码核对 RGB，并检查 EXIF、XMP、ICC、IPTC 等属性未夹带。所有保留页再做本地 OCR，若检出被选择隐藏的完整值则阻断。OCR 不能证明未知、未标注敏感内容全部消失，仍须人工逐页核对。
- 输出上限 50 MB、区域 3,000 项；不得删掉全部页面；解析有阻断项仍不可导出。产物重新生成比对通过后才签发链接，固定文件名不泄露原名，旧签发链接保持原有到期规则。
- API 的重处理与后台任务共用 PostgreSQL 排他槽位；忙时立即返回，避免持有文档锁等待后台发布造成死锁。数据库锁连接丢失时取消 API 的处理线程。
- DOCX 内嵌 PNG/JPEG：每个图片资源 OCR、单独复核/框选，正文仍按文字规则回写；同一图片复用处同步生效。输出图片重编码为无属性 PNG，更新内容类型及关系引用，资源名统一替换，重新解包与 OCR 检查残留。未知矢量、效果、外链图片和其他未支持对象继续阻断；不通过移除未知对象绕过复核。

## 已验证

- `pnpm check`：36 个单元测试、11 条 Bend 法律、13 个反向变异、类型检查与构建通过。
- `pnpm test:isolated`：13 个真实 PostgreSQL 集成测试通过，包括新增页面导出和 API/worker 重任务互斥。
- 桌面 Edge：22 个完整回归通过，覆盖拖拽框选、指定多页、删页撤销、处理预览、PDF 下载及 DOCX 内嵌图片回写；含重任务互斥与坐标显示精度修正后的复验。
- 合成 DOCX/XLSX 由本机 LibreOffice 在禁网沙箱中实际打开并转换为 PDF；逐页文字提取/OCR 未检出已选择的原值。可重复命令：`SOFFICE_BIN=<本机可执行文件> node --import tsx scripts/check-office-render.ts`。合成渲染产物保存于 `.data/evals/office-render/`，不使用用户私有材料。
- 0°/90°/180°/270° 合成页面像素复验；JPEG 转 PNG；空白/无文字图像；越界区域与全删拒绝；版本冲突；快照篡改拒绝；原件字节不变；已签发链接兼容；产物篡改拒绝。

已安装 `@embedpdf/pdfium@2.15.1` 提供原生红删函数，但不能仅依据 API 名称宣称安全。上游的新运行时变更涉及同一文本对象多区域残留、替代文字、嵌套表单和共享图片等修复；npm 的新运行时仍是 `3.0.0-next.0`。未验证其与当前 WASM 的对应关系，因此本次没有擅自切换预发布运行时或放开原生模式。
