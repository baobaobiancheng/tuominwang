# Bend 方法接入与验证边界

## 方法和范围

使用用户提供的 `/Users/admin/fde/bend` 源码，不是安装 Codex 插件，也不是用 Bend 重写业务工程。保留 TS、React、Fastify、PostgreSQL 和独立 worker。按 ponytail 原则，仅抽出需要统一约束的纯导出及还原策略；Bend 校验不调用远程服务或模型。

工具版本为 Bend 2.0.25，源码提交 `ff7a40cc9070a34c78399ecd2bbe46a044ad9b4b`。`scripts/bend-lock.json` 固定检查器、编译器、命令入口和 Base 的 SHA-256。源码缺失、改变或编译产物过期时，检查失败，不静默跳过。`BEND_NO_TELEMETRY=1`，仅使用本地导入。

## 第一组法律

`LAWS.bend` 根据既定导出约束首次形式化，`PROOF.bend` 对任意布尔前提逐项证明：

1. 解析/识别未完成，不允许导出。
2. 请求版本不是当前复核版本，不允许导出。
3. 对象覆盖不完整，不允许导出。
4. 仍有待复核项，不允许导出。
5. 复核快照不匹配，不允许导出。
6. 全部前提满足时允许进入后续导出校验，不能以拒绝所有请求冒充安全实现。

法律固定的是上述语义，不得为了通过证明擅自弱化。用户可审阅此处的自然语言与 `LAWS.bend`；后续业务规则变化需要明确确认。

## 第二组法律：假名还原

将既定“独立授权、版本绑定、未知/歧义代号不猜测还原”要求建模为四个布尔前提：已授权、当前版本、代号已知、映射无歧义。任一前提不成立时拒绝；全部成立时允许后续还原，共新增五条法律，不修改原六条导出法律。变形代号的检测与映射查询仍由 TS 桥接验证，不宣称形式化证明了任意文字变形的识别。

API 在当前用户事务中读取项目/文档、核对版本与不可变复核快照，才构建可用映射集；`mappings.ts` 从这个集合判断已知代号及歧义，调用 Bend 生成的 `restoreAllowed`。仅一次回填，不递归展开原值中的代号。迁移 008 已加入成员级映射/还原独立授权，项目锁内重查权限；这些 SQL/并发行为由集成测试验证，不扩大 Bend 证明范围。

## 真实执行路径

`packages/core/export-policy.bend` 是纯决策函数唯一源码。Bend 自带模块编译器生成 `export-policy.generated.js`，TS 的 `export-gate.ts` 直接调用该模块，不另外手写一份布尔决策。

申请导出、worker 开始生成及提交结果前、签发新下载链接均调用统一检查。TS 桥接从服务端数据提取状态、版本、对象覆盖、人工决定、文档及租户/项目绑定、解析版本、原文哈希和快照标记。未知格式、缺失覆盖、损坏行列锚点、未知决定均拒绝。既有的标记范围、重叠、敏感值残留、产物完整性和权限校验继续执行。

迁移 002 前的粘贴 TXT 可以没有对象锚点：仅对 `source_id = null`、TXT、空锚点且空覆盖的既有结构保留兼容。上传文件不使用此例外；显式 blocked 状态不能被例外绕过。

已签发链接仍在到期前可用，并继续检查实际产物哈希；不把新的导出前提追溯应用到历史链接。这保持用户已确认的下载语义。

## 检查命令

需要本地 Bun、Node 和锁定版本的 Bend checkout；可用 `BEND_ROOT` 指定源码位置。不安装全局命令，不修改 Bend 仓库。

```sh
pnpm bend:build  # 校验法律和证明，再从 Bend 源码生成运行时模块
pnpm bend:check  # 校验法律和证明，检查运行时模块与源码一致
pnpm bend:test   # 13 个能通过类型检查但违反法律的变异必须证明失败
pnpm check      # 上述检查 + TS 类型 + 单元测试 + 网页构建
pnpm test:isolated
pnpm test:e2e:isolated
```

变异包括分别删除导出的五项前提、还原的四项前提，以及两套策略的无条件允许/无条件拒绝。变异仅发生在新建临时目录；不修改正式法律或源文件。单元测试穷举导出 32 种、还原 16 种布尔输入，测试桥接的缺失、重复覆盖和损坏行列、快照绑定与未知/歧义代号；数据库与浏览器测试检验实际调用点。

## 不能宣称的保证

Bend 仅证明已建模的布尔前提与放行结果之间的关系，不证明这些前提是否忠实描述全部业务事实。TS 桥接、文件解析、PDF/OCR、NER/AI、加密、SQL/RLS、租约竞争、JS 编译器和运行时仍在可信基础或测试范围内，未获完整形式化证明。Bend 本身年轻，官方源码说明也提示实现未完全审计。不能由本次接入推出“零泄露”“不会有 bug”或“一期已完成”。

粘贴文本与还原文本上限 100 KiB；文件上限 50 MiB。大文件与租约/崩溃的实际测试不属于 Bend 证明，见各批验收记录；复杂文件安全回写与后续权限发行仍需单独完成。
