在用户实际使用的 Edge 标签页中，页面仍显示 `deploy-qa-20261013`，以及两个合成材料验收项目；另一个标签页已登录 `admin`，浏览器共享 Cookie 已切换。旧页面继续用旧项目 ID 请求，新账号没有对应项目权限，服务器返回“记录不存在，或你已无权访问”。

项目和材料都还存在。`admin` 当前没有自己的项目；组织管理员并不会自动获得其他账号的项目原文权限。

### 现在如何开始使用

1. 使用 `admin` 登录线上入口。
2. 左侧展开“新建项目”，输入名称后点击“新建项目”。
3. 在项目中点击“导入材料”，选择文件并“上传文件”；也可通过文字入口提交文本。
4. 识别结束后打开材料，逐项选择脱敏或保留，检查漏标和处理预览。
5. 保存复核，生成处理副本，再“核验并下载”。

同一浏览器的标签页共享登录账号。需要同时用两个账号时，请使用不同浏览器配置文件。换号会清除旧账号未保存的页面草稿；应先保存再切换账号。
