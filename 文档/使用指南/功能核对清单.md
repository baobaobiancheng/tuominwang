# 脱敏汪功能核对清单

核对日期：2026-10-13。适用：当前电脑网页版。

本轮线上问题与实际验收见[线上项目报错修复与入口核验](线上项目报错修复与入口核验-20261013.md)。跨标签页切换账号会自动清除旧工作台并重新载入当前账号项目，未保存草稿请先保存。

本清单根据前端实现、接口调用与已有浏览器测试代码整理，是使用指南的功能索引。**这里的“结果”表示当前设计应产生的结果，不表示本轮已完成实操。** 本轮截图、下载文件和实际操作结论以主使用指南及实操记录为准；存在测试用例也不等于本轮已经运行。

## 推荐操作顺序

登录 → 新建/选择项目 → 导入材料 → 等待识别 → 按实体检查并逐处修正 → 补录漏标 → 查看处理预览 → 保存复核 → 生成副本 → 核验并下载。需要项目词表时，尽量先维护词表再导入材料。

确认交互：可撤销的当前草稿操作（组处理、批量决定、补录漏标、跨页添加区域、从副本移页、使用已有同实体假名）点击后直接生效，可通过现有撤销恢复。持久修改、放弃未保存内容、重新识别、删除原件等使用页面内“操作确认”，选择“确认执行”或“取消”；Esc只取消最上层确认。刷新/关闭浏览器的未保存保护仍由浏览器显示。

所有“待确认”都需决定为“脱敏处理”或“保留原值”。规则无命中、预览正常、任务已完成分别是不同状态，均不能单独代表材料已经安全脱敏。

## 1. 登录、项目与导航

| 功能/入口 | 操作步骤 | 应看到的结果 | 禁用或隐藏原因、限制 |
|---|---|---|---|
| 登录工作台 | 输入账号、密码 → 登录工作台 | 显示可访问项目和当前账号 | 请求处理中不可重复提交；会话失效后需重新登录 |
| 新建项目 | 左侧展开新建项目 → 输入项目名称 → 新建项目 | 新项目出现在左侧，进入项目材料列表 | 请求处理中锁定；名称需符合输入要求 |
| 选择/搜索项目 | 点击左侧项目；项目较多时使用“搜索项目” | 切换项目材料与工具 | 搜索仅筛选已载入项目；列表有“更多项目”时需继续加载；未保存内容会先提示 |
| 收起/展开侧栏 | 点击侧栏顶部按钮 | 改变工作区宽度 | 不改变项目或材料内容 |
| 打开/切换材料 | 材料列表点击行，或复核页左侧材料导航 | 显示原文、候选及当前版本 | 需查看原件权限；未保存草稿切换前需确认放弃 |
| 刷新与更多文件 | 材料列表“刷新材料”“更多文件” | 刷新状态/加载下一批材料 | 当前列表并非一次载入项目全部材料 |
| 退出 | 点击账号旁“退出” | 返回登录页面 | 未保存复核、词表、权限或输入内容可能出现放弃提示 |

## 2. 导入文件与文本

| 功能/入口 | 操作步骤 | 应看到的结果 | 禁用或隐藏原因、限制 |
|---|---|---|---|
| 粘贴文本 | 导入材料 → 待处理文本 → 提交并识别 | 保存材料并排队识别，随后打开复核 | 需导入权限；非空；不超过 100 KiB（按 UTF-8 字节计量） |
| 选择文件 | 导入材料 → 选择文件 → 上传文件 | 各文件显示上传状态，保存后出现在材料列表 | 每批最多 20 个非空文件，单文件上限 50 MiB；页面文案显示 50 MB |
| 支持格式 | 选择 TXT、MD、CSV、DOCX、XLSX、PDF、PNG、JPG/JPEG | 按格式解析原文/表格/页面 | 文本类应为 UTF-8；不支持 DOC、WPS、PPT、压缩包等未列格式 |
| 选择目录 | 导入材料 → 选择目录 → 上传文件 | 保留目录相对路径显示材料 | 仍受每批 20 文件限制，不会自动分批；同批不可有重复路径 |
| 上传记录 | 导入材料底部 → 查看记录/刷新记录/更多上传记录 | 显示批次时间、首文件、已保存数量 | 每次加载 10 条记录；已保存不等于识别完成 |
| 继续上传 | 记录中“继续上传” → 补选原文件/原目录 → 上传文件 | 跳过已经保存的文件，继续剩余文件 | 必须匹配原路径、大小与内容校验值；文件已改须新建上传；旧批次缺内容校验时不能续传 |
| 上传失败重试 | 保留原选择后重新上传，或从记录继续 | 已保存文件不重复写入 | 容量/数量超限、无权限、不支持格式、网络中断等需先处理对应原因 |
| 提交新文本/返回材料列表 | 复核页顶部或导入页顶部对应按钮 | 返回导入或列表 | 未上传文件、未保存复核/词表会提示，不会自动替用户保存 |

## 3. 识别与复核

| 功能/入口 | 操作步骤 | 应看到的结果 | 禁用或隐藏原因、限制 |
|---|---|---|---|
| 自动规则识别 | 提交材料后等待任务完成 | 展示规则候选、待确认数及复核版本 | 候选不是最终结论，仍需人工检查原文 |
| 重新识别 | 复核顶部“重新识别” → 确认 | 生成新复核版本 | 需复核权限；未保存、有冲突、任务排队/运行中不可操作；原有处理决定不自动沿用 |
| 识别实体候选 | 顶部“识别实体候选” → 确认 | 增加人名、机构、地址候选 | 仅模型可用且同时有复核、模型管理权限时显示；不是云端模型配置界面 |
| 任务状态 | 复核顶部任务提示 | 排队中/处理中/已完成/失败/已取消及错误原因 | 页面显示状态，不应把任务完成等同导出核验通过 |
| 取消任务 | 任务排队或运行中 → 取消任务 | 任务转为已取消 | 必须拥有任务声明的全部所需权限；任务结束后不显示 |
| 重试任务 | 失败或取消任务 → 重试任务 | 再次提交任务并刷新文档 | 需任务所需权限；材料过期、草稿未保存或版本冲突时不可重试 |
| 原文高亮/分段 | 原文审查；长文使用上一段/下一段原文 | 查看敏感标记和对应原文段落 | 原文只读；分段不代表只保存当前段；坐标使用完整原文位置 |
| 按实体分组 | 敏感标记 → 按实体 | 同类型、可确认完整同值的标记合并，显示次数与三类决定计数 | 仅涵盖已有标记；长值片段按位置独立，不能据相同前缀推定同实体 |
| 实体筛选/选择 | 选择类型或输入原值 → 勾选组/筛选结果全选 | 显示所选组数和出现处数 | 分组每页 50 组；选择可跨页；筛选外已有选择会明确提示 |
| 所选组脱敏/保留/恢复待确认 | 核对所选组数/出现处数 → 对应按钮（直接生效） | 所选已有标记的决定进入草稿 | 需复核权限；仅改草稿，可撤销；保留每处既有脱敏方式，不自动统一自定义替换或假名 |
| 单处定位与例外 | 点击组原值；上一处/下一处；编辑此处 | 定位原文并进入该标记的逐条表单 | 同值组允许某一处保留或使用不同方式；不一致时显示核对提示 |
| 逐条复核 | 敏感标记 → 逐条复核 → 修改决定 | 待确认/脱敏处理/保留原值进入草稿 | 每页 50 项；未显示页的决定仍在完整草稿中；只读用户不能写入 |
| 改信息类型 | 逐条复核 → 信息类型 | 当前标记变为所选类型 | 会清除该处原有替换方式并改为人工标记，需重新核对 |
| 类型占位符 | 某标记选脱敏 → 脱敏方式选类型占位符 | 导出以类型占位符替代 | 图像文字不支持此文字替换方式，采用像素清除 |
| 部分遮盖 | 脱敏方式选部分遮盖 → 输入保留前/后几字 | 预览保留两端，中间遮盖 | 输入合法性及是否充分遮盖会再校验；图像文字不支持 |
| 自定义替换 | 脱敏方式选自定义替换 → 输入替换文字 | 使用指定文字 | 不创建还原关系；替换值长度与保留符号受校验 |
| 人工补标/删除标记 | 在原文选中文字 → 将选中文字加入标记；或逐条“删除标记” | 新增待确认自定义项或删除现有项 | 需复核权限；最多 32,768 项；删除标记并不等于已处理原文 |
| 全文查找 | 全文查找 → 输入精确文字 → 全部文字/敏感标记内/敏感标记外 → 查找 | 返回匹配位置；可点击、上一处/下一处或下一组 | 不是正则搜索；最多输入 200 字符；保留项不算敏感标记；命中完整在同一标记内才算“内” |
| 全文漏标检查 | 漏标检查 → 检查全文漏标 → 定位问题 → 补录全部漏标到草稿 | 检查已知原值重复位置；点击补录后直接加入待确认草稿，可撤销 | 不发现未知敏感项；草稿修改会使检查失效；单值最多 2,000 字符、累计匹配 32,768 处，材料/原值过多会拒绝完整检查 |
| 漏标冲突处理 | 查看同值策略、保留项、范围冲突提示 | 定位后逐处人工解决 | 不自动覆盖已有保留或白名单建议；无映射权限时不能补入需要沿用假名的项 |
| 当前文档批量复核 | 批量复核 → 类型/状态筛选 → 核对范围 → 批量脱敏或保留（直接生效） | 符合筛选的已有标记进入草稿，可撤销 | 与项目多材料批量不同；“全部状态”可覆盖已决定项，必须核对范围 |
| 撤销/重做 | 撤销修改/重做修改 | 恢复保存前草稿步骤 | 最多最近 10 步；保存后不提供历史版本任意回滚 |
| 处理预览 | 原文区域“处理预览” | 展示当前段落、当前草稿的文字替换结果 | 待确认项仍显示原值；草稿变化后需刷新；不是最终下载文件 |
| 保存复核/版本冲突 | 保存复核；冲突时先核对并重新载入最新复核 | 正常保存后版本更新；冲突时拒绝覆盖 | 无修改、只读、处理中或材料非复核态不可保存；重新载入会放弃本窗口未保存修改 |

## 4. 页面、图片与导出

| 功能/入口 | 操作步骤 | 应看到的结果 | 禁用或隐藏原因、限制 |
|---|---|---|---|
| 页面翻阅 | PDF/图片/含图片 Word → 页面或图片资源下拉直达，也可上一页/下一页 | 显示对应原件页面或内嵌图片 | Word 是图片资源顺序，非 Word 页码；复用同一图片资源时处理同时生效 |
| 区域框选 | 原件上拖动或输入坐标 → 选区域类型 → 添加本页区域 | 黑框显示已添加区域 | 蓝框仅是待添加范围；支持敏感区域/印章/签名/人脸标签，标签不代表自动识别能力 |
| 多页同位区域 | 框选 → 起始/结束页 → 应用到指定页 | 按相容页面坐标添加区域，可整批撤销；不兼容、已删除、已覆盖和失败页面分别列出 | 要核对不同版式页面；总区域上限 3,000；单页或非法范围不可操作 |
| 移除区域/页面撤销 | 移除区域 N / 撤销页面修改 | 删除区域或回到前一步页面草稿 | 页面撤销最多 10 步；仍需保存复核 |
| 从副本移除页/恢复页 | 多页 PDF → 从副本移除此页（直接生效）；点恢复此页还原 | 副本排除/包含该页，原件保留，可撤销页面修改 | 不能删除到零页；DOCX 内嵌图片不提供此删页入口 |
| 图像输出方式确认 | 勾选对应 PDF 图片化/PNG像素清除/DOCX内嵌图清除选项 | 明确采用图像像素处理 | 未确认并保存时阻止导出；可选四种清除色。整体默认清像素，逐项自定义、假名及选择性星号可先清除再绘字；人工清除区域最后生效，不能恢复被清除像素 |
| 检测实体位置调整 | 调整识别实体位置 → 选择实体与整组或单框 → 拖动或8方向调整 → 保存复核 | 遮盖采用绑定后的实际坐标，可清除调整并撤销 | 类型或范围变化需先保存再重新选；原文残留仍阻止签发，不能把框移走当脱敏完成 |
| 页面处理预览 | 查看本页处理预览 | 查看本页候选及框选区域的处理图 | 已移除页或无编辑权限时不可用；草稿变化后需重新预览 |
| 生成副本 | 所有候选确认并保存 → 导出已选标记的处理副本 | 提交独立副本任务 | 无导出权限、未保存、有待确认项、版本冲突、对象覆盖阻断或图像方式未确认时不可用 |
| 核验并下载 | 副本生成完成 → 核验并下载相应格式 | 再核验当前版本后获得下载文件 | 必须是成功完成的导出任务；新签发链接有效期 5 分钟；旧链接在到期前可能仍可用 |
| 各格式导出结果 | 打开下载副本与原文对照 | TXT/MD/CSV/DOCX/XLSX/PDF保留对应扩展名；图片为PNG | PDF为不可选字的图片型副本；XLSX是值快照，不保留公式/超链接/条件格式/数据验证；DOCX移除超链接和动态域指令，保留已显示文字 |

## 5. 项目词表、跨材料复核与假名

| 功能/入口 | 操作步骤 | 应看到的结果 | 禁用或隐藏原因、限制 |
|---|---|---|---|
| 添加/移除词条 | 材料列表 → 项目词表 → 名称、信息类型、黑/白名单 → 添加；或移除 | 修改当前词表草稿 | 需词表管理权限；最多 1,000 条、单值 200 字符；相同名称+类型不能重复 |
| 导入名单 XLSX | 项目词表 → 导入名单 XLSX → 核对草稿 → 保存词表 | 替换当前词表草稿，再显式保存 | 不超过 5 MiB/1,000 条；表头必须为“名称或代号、信息类型、名单”；导入本身不是保存 |
| 导出名单 XLSX | 项目词表 → 导出名单 XLSX | 下载已保存词表，可作为导入模板 | 有未保存修改时禁用 |
| 保存词表 | 保存词表 → 阅读影响并确认 | 项目材料标为需重新识别，旧复核记录仍保留 | 黑名单补候选，白名单给保留建议，均需复核；旧副本不能新签发链接，已签发链接到期前仍有效 |
| 项目批量复核 | 材料列表 → 项目批量复核 → 勾选材料 → 类型/决定/仅白名单筛选 → 核对批量范围 | 显示每份材料版本及受影响项数 | 最多 20 份；只处理已加载且勾选材料的待确认项；非复核态材料不能选 |
| 确认批量保存 | 核对范围后 → 确认批量保存 | 直接保存所选材料的新复核版本 | 任一版本冲突整批不保存；正在生成的旧副本任务会被取消；不是当前文档草稿操作 |
| 撤销本次批量复核 | 当前批量结果 → 撤销本次批量复核 → 确认 | 恢复该次操作前决定并创建新版本 | 材料已再次修改时拒绝撤销；只针对当前界面保留的本次回执 |
| 创建/选项目假名 | 逐条脱敏 → 选择项目假名 → 创建新假名或确认同一实体并使用 | 创建新假名需页内确认并存储还原关系；“确认同一实体并使用”直接改该处草稿 | 需复核与映射权限；同名不自动合并；不同实体应创建独立假名 |
| 查看假名映射 | 材料列表 → 查看假名映射 → 更多映射 | 显示假名、原值、类型 | 需映射权限；每次 20 条；该页面含原始敏感信息 |
| 还原假名 | 保存含假名的复核 → 还原假名 → 粘贴文本 → 确认还原 | 显示还原结果，可下载还原文本 | 需还原权限；最多 100 KiB；仅使用当前材料版本已确认的假名，不猜测未知/变形代号；下载再次检查权限与版本 |

## 6. 权限、配额、审计与删除

| 功能/入口 | 操作步骤 | 应看到的结果 | 禁用或隐藏原因、限制 |
|---|---|---|---|
| 组织名称 | 侧栏组织管理 → 修改名称 → 保存组织名称 | 显示保存提示 | 组织所有者/管理员可修改；普通成员只读 |
| 创建成员账号 | 组织管理 → 成员账号/初始密码 → 创建成员账号 | 创建账号，再到项目分配权限 | 密码至少 12 位，保存后不再次展示；组织账号不会自动获得项目资料权限 |
| 组织角色 | 组织管理 → 指定成员角色 → 确认 | 成员/管理员角色更新 | 所有者角色固定；角色与项目授权独立 |
| 停用/启用账号 | 组织管理 → 停用或启用指定成员 → 确认 | 更新账号状态 | 所有者不能在此停用；停用会结束其登录会话与处理任务 |
| 项目成员授权 | 材料列表 → 项目成员 → 选择成员 → 勾选权限 → 保存成员权限 | 更新该项目操作范围 | 需项目成员管理权限；不能修改自己或项目所有者；停用账号不能新增授权 |
| 权限类别 | 逐项选择查看原件、人工复核、导出副本、查看与创建映射、假名还原、模型管理、项目成员管理、导入材料、词表管理、删除材料 | 用户仅见/可操作授权范围 | 没有查看原件但有导出/还原/删除权限时可能显示操作列表而非原文；权限不是单一“管理员”开关 |
| 清空项目权限 | 项目成员 → 清空权限 → 保存并确认 | 撤销该成员对项目的访问 | 不会立即让已签发短期链接失效，需等链接到期 |
| 查看/保存材料配额 | 组织管理 → 查看材料配额 → 修改容量MiB/材料数 → 保存 | 显示已用量与新上限 | 管理员入口；原始数据计量不含派生副本、模型文件；配额不是磁盘实际占用 |
| 项目操作记录 | 材料列表 → 操作记录 → 刷新/更多 | 查看时间、操作、账号编号、对象编号及授权摘要 | 需项目成员管理权限；每次 20 条 |
| 组织操作记录 | 组织管理 → 操作记录 → 刷新/更多 | 查看组织范围记录 | 组织所有者/管理员入口；无日志导出或全文搜索入口 |
| 删除材料 | 复核顶部或材料操作行 → 删除材料 → 核对不可恢复提示 → 确认 | 删除该材料原件、复核与副本记录并刷新列表 | 需删除材料权限；不能恢复；共享词表/假名映射保留；已有签发链接关联文件到期后清除 |
