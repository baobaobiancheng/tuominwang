# 第一批文件基础验收

更新日期：2026-09-23。状态：第一批的文件与版本基础闭环通过下列验收；复杂格式完整覆盖、安全回写和效果验收仍属于后续批次，不是完整一期交付。

交付与验收仅面向电脑网页版；手机端不纳入本期范围。

## 已实现

- 单文件、多文件、目录上传；每批最多 20 个文件，单文件存储上限 50 MiB。逐文件保存状态与同一请求重试幂等，同名不同请求不覆盖。
- 加密批次记录、分页查询与跨刷新续接；重新选择原文件后核对路径、大小及 SHA-256，自动跳过已入库文件，响应丢失也不重复导入。旧版未记录哈希的未完成批次明确提示新建上传，不伪造内容校验。续接为文件级，不是分块断点续传。
- 加密保存不可变原件和文件名；解析版本、字符/单元格锚点、覆盖状态；增量迁移 002 为既有复核数据建立快照，运行账号无权修改快照。
- UTF-8 TXT、Markdown、CSV 上传、规则识别、人工复核、同格式导出；TXT 完整 50 MiB 边界已实测。大文本按 32,768 字符分段读取，保留全文定位与未保存决定；直接粘贴上限仍为 100 KiB。CSV 不执行公式，导出中和公式前缀、保留行列结构，拒绝跨单元格标记。
- Markdown 作为源码复核，不执行 HTML、不加载外链，遇到 HTML/图片对象明确阻断。
- DOCX 对象级文字解析及回写覆盖正文、表格、跨 run 号码、页眉页脚、文本框、修订、批注、属性；XLSX 包含隐藏工作表、独立单元格值、批注及公式缓存。副本移除 Word 动态域/超链接，XLSX 输出值快照，不执行或保留公式、超链接、条件格式及数据验证。图片、嵌入对象、外部内容引用、无公式缓存及未知部件继续阻断，不能称为完整 Office 支持。
- ZIP 采用逐项解压、CRC 和实际字节数检查；拒绝重复路径、链接、加密包及不安全 XML。上限为 10,000 个压缩部件、每项展开 50 MiB、累计 256 MiB、20,000 个内容对象、XML 深度 128。导出从不可变原件重新解析、核对清单、重写并重开检查残留。
- CPU 密集处理移入独立线程，512 MiB JS 堆与 120 秒超时（PDF 解析最长 30 分钟）；取消/失租终止线程。数据库任务全局单槽，1 秒续租检查，保留 30 秒租约及最多 3 次尝试。V8 堆上限不等同于进程 RSS 上限。
- PDF/PNG/JPEG 本地解析和 OCR，页级加密预览、字符坐标及原生文字/OCR 按位置去重；旋转 0/90/180/270 度覆盖。PDF 超过 300 页拒绝，单页渲染超过 2,500 万像素拒绝，多帧图片拒绝。附件/脚本显式阻断；PDF/图片当前不提供导出，安全回写留在第四批。
- 项目/文件分页、取消及失败任务手动重试；旧复核、签发链接和下载行为保留。
- 前端补充上传未完成的离开提示、失败原因和行列定位。无研发过程文案、模拟功能入口或会话内容。
- 按用户指定的 Bend 方法加入 `LAWS.bend`、`PROOF.bend` 和编译产物一致性检查。申请导出、后台生成及提交、签发新链接统一核对对象覆盖与不可变快照；既有到期前有效的下载链接不追溯撤销。证明只覆盖布尔导出策略，具体边界见 `Bend方法与验证边界.md`。

## 已验证

- Node 24.21.0 下 `pnpm check`：6 条 Bend 法律、7 个反向变异、编译一致性、类型检查、22 项单元测试及构建通过。Node 26 的同组检查亦通过。32 种布尔输入、覆盖/快照桥接与 OCR 字符坐标均有回归。`pnpm audit --json` 本次报告 0 项已知依赖漏洞，不等于没有安全缺陷。
- `pnpm test:isolated`：四个真实 PostgreSQL/API/worker 场景通过。包括原有安全回归及上传幂等、原件不变、快照 UPDATE 拒绝、跨项目拒绝、取消重试、CSV 导出和公式中和、损坏 CSV/无效 UTF-8/Markdown 图片/PDF/文本超限阻断；新增导出申请、任务排队后覆盖改变、签发新链接、原文与解析版本变化时的阻断，以及原有链接仍有效的兼容验证。
- `pnpm test:e2e:isolated`：16 项 Edge 电脑浏览器场景通过，新增 DOCX/XLSX 二进制下载、PDF 翻页预览、分段文本跨段补标及未保存决定保持。浏览器场景使用独立测试账号；登录按 IP 限流，已登录请求按账号限流，均未放宽原有额度。原有上传续接、目录、版本冲突与下载核验保留，未运行手机验收。
- Node 24 与 Node 26 下的隔离集成最终均为 6 项场景通过；新增长任务真实进程取消、SIGTERM、SIGKILL、租约代际接管、有限重试耗尽、取消后旧结果无复核快照，以及后续任务仍能运行。接管测试仅将测试库内该任务租约提前到期，未改变业务租约时长。
- 截图与 trace 位于忽略的 `test-results/`，不作为公开发行内容；不包含业务账号的验收数据。
- 隔离测试创建随机测试数据库及临时数据目录，结束后删除本次测试库和临时目录，不删除业务材料。浏览器测试运行前停止占用端口的开发服务，结束后恢复。
- 本机现有数据库已执行 004 增量迁移，API/worker/网页已重启，网页代理健康检查通过。未删除既有业务表或原件。
