# 7处原生文件哈希差异核验（2026-10-14）

## 结论

7/7 ASAR声明SHA256均等于 npm 同版本官方发布tarball内原始二进制的SHA256。与DMG实际发布文件比较，仅发现Mach-O代码签名及相关结构字段变化，未解释字节数为0；7/7系统 codesign --verify --strict 返回0。原始ASAR声明与实际成员的SHA256仍然不同，不能把它们改写成“原始哈希一致”。

## 比较方法

- 读取npm元数据和tarball，逐个验证dist.integrity（SHA512）。不安装或运行包。
- 原生arm64：签名blob替换、LINKEDIT虚拟/文件大小变化。
- ONNX x64：原包无LC_CODE_SIGNATURE；发布包追加最后16字节签名load command，更新ncmds/sizeofcmds，增加签名及最多15字节零对齐。
- 归一化只作用于内存比较副本，原件完全未修改。要求签名段位于EOF、LINKEDIT末尾等于EOF、所有非签名字节逐字节相等。
- 该证据说明差异位置与签名有效性；无法还原厂商具体构建流水线的历史步骤，也不证明算法运行正确。
