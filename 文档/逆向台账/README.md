## 状态定义

### static_depth

- `S1`：入口/声明观察，未完整展开。
- `S2`：关键契约/局部调用链追踪，非完整链路。
- `S3`：完整静态链路逐段闭合。

### runtime_status

- `R0`：未逐项运行验证。
- `R1`：仅界面/入口观察。
- `R2`：逐项端到端运行验证。

### implementation_status

- `I0`：未逐项评估。
- `I1`：已有独立相关实现，仍有差异/缺项。
- `I2`：对应能力明确未实现/未启用。
- `I3`：不属于当前网页版功能对齐范围。
- `I4`：逐项实现及验证完成。
