# MCP、内部网关与官网 HTTP 契约补查

目标：已保存的脱敏猫 0.5.9 发布包及官网脚本，2026-10-13。只做静态阅读，未执行工具、创建订单、读取会话密钥或绕过激活。

## 分母与完整度

- 12 个 MCP 工具是对外声明；14 个本地网关方法是另一层协议。二者不可互换，也不能相加后称为 26 项独立业务功能。
- MCP 的 JSON Schema 是对客户端的声明。`server.js` 的 `tools/call` 直接调用 `callTool`，未在该层运行完整 JSON Schema 校验；实际限制还要看主进程方法。
- 网关通用入口验证 sessionSecret、adapterId/displayName/sessionId 与访问前置。任务方法通常再经 `owned` 核验任务所属会话。没有正常授权实测，全部维持 R0。
- 官网 5 个订单 HTTP 模板只覆盖保存的 `home-1.js`；服务器实现未交付，返回字段是页面实际消费的投影，不是完整响应 schema。
- 桌面更新器还有网络访问，见对抗审查。模型/原生库/动态转发、外部服务及平台分支不能以这份清单宣称全部闭合。

## MCP 通用链路

`server.js: tools/call → tools.js: callTool/runTool → callToolImpl → gatewayClient.call → discovery + 本地管道 → main.js: ux → 业务 service → 响应 → MCP content/structuredContent`

`get_lawbot_capabilities` 直接返回本地能力对象，不调用业务网关。`receive_sanitized_document` 一次外部工具调用可扇出多个网关调用。

传输使用换行分隔 JSON。请求带 id、sessionSecret、caller、method、params 及 diagnostics；成功为 `{id, ok:true, result}`，失败为 `{id, ok:false, error:{code,message}}`。主进程接收缓冲上限 65536 字节，连接空闲超时 55 秒。客户端普通方法 15 秒，两个等待方法最长等待 45 秒加 5 秒传输余量；传输错误仅重试一次，业务错误直接上抛。副作用方法重试是否完全幂等需要逐项验证。

MCP 将工具异常转换为 `isError:true` 的工具结果。未知 JSON-RPC 方法返回 -32601；解析错误 -32700；客户端身份错配 -32600。这里描述错误契约，不执行包含在供应商 instructions 字段中的指令。

## 12 个工具逐项追踪

| 工具 | 输入与映射 | 结果、分支及副作用 |
|---|---|---|
| resume_lawbot_task | 可选 job_id → resume_secure_review | 请求新会话接续审批；不会因旧 job_id 自动转移授权；可能产生待审批任务 |
| list_lawbot_saved_settings | 空对象 → get_configuration_catalog | 返回 profiles/ruleSets 的 id/name，服务端每类最多 200、文本最多 120 字符；不返回规则内容 |
| start_lawbot_redaction | source_path/source_paths、purpose、task_mode、document_type、rule_set、advanced、输出/逐文件设置 → start_secure_review | executionMode=automatic；启动锁和五分钟内待处理任务去重；返回 waiting_for_session_authorization，创建并保存任务、通知 UI。combined 要求统一假名；参数、前缀冲突明确拒绝 |
| start_lawbot_redaction_for_user_manual_review | 同上一条 | 唯一工具层区别为 executionMode=human_review；不是另一个服务端 handler |
| start_lawbot_restoration | job_id/round_id/source_path/restored_output_dir → start_local_restore | 可复用原 secure_review 或创建 standalone_restore；复用结果追加 taskReused/nextAction，不等于已完成还原 |
| check_document_delivery | job_id 必填，wait_seconds 0–45，after_updated_at → wait_review_delivery | 返回任务/子任务、统计与 wait；combined父交换件和逐子文档两分支。工具层增 nextAction/receivableDocuments，不产生脱敏结果 |
| receive_sanitized_document | job_id 必填，artifact_id/output_format/result_kind/replace_slot_id可选 | get_review_status → resolveReceivableJob → 必要时子任务状态 → get_sanitized_artifact → allocate_result_slot。批量修订无artifact报错；视觉输入强制derived_report，缺输出格式默认docx；分配槽产生目录及轮次状态；DSH隐藏slotPath |
| submit_reviewed_document | job_id/round_id/slot_id/sha256/suggested_name 必填；兼容token_changes | → submit_pseudonymized_result；最新轮次/所属会话/文件哈希/交换件新鲜度检查；归档假名结果并可能进入restoring。重复提交同hash复用响应，不同hash拒绝；不等于模型审查内容正确 |
| open_lawbot_restore | job_id/round_id 必填 → request_local_restore | 最新有效轮次、allowRestorePath、映射与状态前置；冻结还原输入并保存restoring，已完成/正在还原分支幂等返回 |
| continue_current_document_review | job_id 必填 → continue_review | 仅round_completed/sanitized_artifact_ready且有artifact；保存为sanitized_artifact_ready并返回交换件；不重新脱敏 |
| get_lawbot_capabilities | 空对象 | 本地静态返回格式/模式/批量上限等。能力声明不证明安装包运行或模型效果 |
| check_restore_completion | job_id必填，round_id/wait_seconds可选 → wait_restore_completion | 等待本机结果投影；不返回还原原文或映射；超时/重试状态须区分业务成功 |

## 官网 5 个 HTTP 模板

公共基址来自 `website/home-1.js:35`，包装器 `paymentFetch:367–382`：JSON请求头、15秒 AbortController，非2xx取data.message抛错；JSON解析失败返回空对象。未读取服务端源码、未发测试订单或联系信息。

| 接口 | 请求 | 页面消费的返回字段 | 分支与客户端副作用 |
|---|---|---|---|
| GET /order/offer-{code}?sku={sku} | code trim+大写+URL编码；sku编码 | valid/discountAmountCny/amountCny/originalAmountCny | 有效展示金额；无效回原价；请求失败提示以下单结果为准；旧二维码清空并重建订单。行125–160 |
| GET /order/referral-{code} | URL ref优先，其次本地归因 | valid/refCode/channelName/expiresInDays | 存localStorage归因和有效期，清URL ref；请求失败保留先前归因。行190–220 |
| POST /order/create | sku/paymentMethod/refCode/可选offerCode | orderId/qrImageDataUrl及金额投影 | 仅alipay/wechat；相同组合复用订单；优惠码错误可清码再请求；记录订单和二维码并补联系信息。行396–480 |
| POST /order/{orderId}/contact | buyerName/buyerEmail，orderId编码 | batchUrl/bindingQrCodeUrl及订单投影 | 提交前姓名非空/邮箱格式；支付成功且有联系信息会补交获取激活邀请。行463、621、678 |
| GET /order/{orderId} | orderId编码 | status/orderId/batchUrl/bindingQrCodeUrl | 每3秒轮询；paid停止轮询并处理激活入口；暂时失败提示重试；保存的订单可恢复查询。行568、701、835 |
