## 平台与验证边界

- No source license activation or competitor protected workflow executed
- OS safeStorage/local CMK/password prompt, native file chooser/shell and native atomic path behavior remain source-platform domain; cloud uses authenticated upload/immutable objects/tenant AEAD/CAS/receipt adapter
- Ranges record this named finite graph; do not infer whole renderer or whole product closure from these nodes
- Own codec/API tests are separate implementation evidence and are not used to assert source runtime or source static depth
